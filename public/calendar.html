Course Calendar

Stage Course parses a pasted course page (like the ENGG 1000 section list) into planner sections. Add to Calendar handles the schedule-text formats below.

Handles both formats: lines ending in a date range like 03/09/2026 - 24/09/2026. Works with the original Topic / Days & Times / Room / Instructor layout, and the Section Details layout (Days / Start / End / Room / Instructor / Dates). Paste as many entries as you like, with or without the header row. Each day shows an 8 AM – 8 PM timeline: blocks are placed at their real clock time (top = start, height = duration), so the empty space between them shows every gap. Classes outside that window are clamped and marked with ▴/▾.

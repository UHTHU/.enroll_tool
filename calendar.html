Course Calendar

Handles both formats: lines ending in a date range like 03/09/2026 - 24/09/2026. Works with the original Topic / Days & Times / Room / Instructor layout, and the Section Details layout (Days / Start / End / Room / Instructor / Dates). Paste as many entries as you like, with or without the header row. In the calendar, each day's courses are sorted by time and sized by duration (longer class = taller block).
